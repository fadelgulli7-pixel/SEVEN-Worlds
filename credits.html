SEVEN Worlds · Asset credits

The Old Quarter environment, mission design, interactions and game interface were created for SEVEN Worlds. The following third-party assets power the new urban rescue mission.

Animated field characters

Vanguard by Mixamo, distributed in the three.js examples as Soldier.glb. The game uses the embedded idle, walk and run clips and adds procedural upper-body poses.

Tactical guard

Military tactical suit (LowPolyGameReady) by DanlyVostok, licensed under Creative Commons Attribution 4.0 International. Optimized GLB obtained from cktang88/3d-fps. Changes for SEVEN Worlds: removed a detached headset, attached the face piece to the head, normalized scale and applied original procedural foot placement, crouching and weapon-hand IK. No author endorsement is implied.

Civilian

Michelle character from the official three.js examples, originally from Mixamo. Imported with its skeleton and textures; rescue poses are custom skeletal animation.

Adobe Mixamo usage FAQ permits character and animation use in personal and commercial games. Michelle is embedded as a functional game component, not a standalone model pack. Mixamo restrictions apply to Michelle separately from the CC BY tactical model.

Audio

Original procedural sound design using Web Audio: layered rifle transient, mechanical action, reload, enemy bursts, impacts and low-level ambient wind. No audio was extracted from another game. Playback starts after a user gesture and can be muted.

Reference and independence

This is an original playable urban rescue mission inspired by the gameplay direction the user supplied. It includes no extracted Sniper Fury or PUBG models, environments, audio, logos or game code. No affiliation with those games is implied.
